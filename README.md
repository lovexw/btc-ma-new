# 比特币价格与均线分析工具

一个现代化的比特币价格分析工具，基于 React 18 构建，提供 50 ~ 2411 日多周期均线走势、AHR999 指数、历年定投回测与价格区间统计，数据每日自动更新。

**在线访问**：[https://lovexw.github.io/btc-ma-new/](https://lovexw.github.io/btc-ma-new/)

## ✨ 功能特点

### 📈 专业图表展示
- **高性能价格走势图** - 采用 ECharts 渲染引擎，近 5,000 天数据流畅展示
- **渐变视觉效果** - 优雅的渐变填充和阴影效果，提升视觉体验
- **平滑曲线** - 平滑的价格和均线展示，清晰展现趋势
- **交互式缩放** - 支持鼠标滚轮和滑块缩放，双击重置，轻松查看不同时间段
- **十字准星** - 精确查看任意时间点的价格和均线数据

### 📊 多周期均线指标
支持 7 种不同周期的移动平均线，帮助识别短期、中期和长期趋势：
- **MA50** (50日均线) - 短期趋势指标
- **MA200** (200日均线) - 经典中期趋势指标
- **MA350** (350日均线) - 中长期趋势指标
- **MA700** (700日均线) - 长期趋势指标
- **MA1000** (1000日均线) - 超长期趋势指标
- **MA1400** (1400日均线) - 极长期趋势指标（约对应一轮减半周期）
- **MA2411** (2411日均线) - 超极长期趋势指标

### 📋 均线监控面板
- **实时均线数值** - 显示每条均线的当前精确数值
- **变化率指标** - 显示均线日涨跌幅度，带趋势图标
- **价格对比** - 自动计算当前价格与各均线的偏离度
- **位置提示** - 清晰标识价格在均线上方或下方
- **独立开关** - 每条均线可独立显示/隐藏，支持一键全部显示

### 🧭 AHR999 指数
集成九神（ahr999）《囤比特币》中的囤币指标，辅助定投决策：

> **AHR999 =（比特币价格 / 200日定投成本）×（比特币价格 / 指数增长估值）**
>
> 其中 200 日定投成本取最近 200 日价格的**几何平均**（模拟每日等额定投的持仓成本），
> 指数增长估值为币价与币龄的对数拟合：`价格 = 10^(5.84 × log10(币龄) − 17.01)`，
> 币龄自创世区块日（2009-01-03）起算。

页面中有两处展示：

| 位置 | 内容 |
|------|------|
| 顶部数据卡片 | 当日最新 AHR999 指数及所处分区标签 |
| 历年定投回测卡片 | 每年买入当日的 AHR999 指数及分区标签 |

分区参考（四档）：

| AHR999 | 分区 | 参考策略 | 颜色 |
|--------|------|----------|------|
| ≤ 0.35 | 绝佳抄底 | 历史底部区域，适合加大投入 | 绿色 |
| 0.35 ~ 0.45 | 抄底定投 | 接近底部，定投 + 逢低加仓 | 浅绿 |
| 0.45 ~ 1.2 | 正常定投 | 常规定投区间 | 橙色 |
| > 1.2 | 谨慎止盈 | 错过最佳定投期，注意止盈 | 红色 |

> 指标仅供学习参考，不构成任何投资建议。

### 🎯 历年定投回测
假设自 2016 年起，每年在今日的价格买入并持有至今，回看每一年的定投收益：
- **回测卡片** - 每年一张，突出显示买入价（大号加粗），并附买入当日的 AHR999 指数与分区、累计盈亏金额与收益率
- **红绿标识** - 盈利用绿色、亏损用红色，一目了然
- **自动基准** - 以最新数据日为基准日，同日无数据时自动向前寻找最近的数据

### 🕐 价格区间停留天数
- 按 1 万美元区间统计比特币价格在 1 万美元以上各区间的停留天数
- 支持条形图 / 卡片两种展示模式一键切换
- 直观的横向条形图展示天数占比，一眼看懂价格都去过哪儿
- 高亮当前价格所在区间，悬停或卡片内可查看首次进入与最近出现的日期

## 📂 数据格式

项目使用 CSV 格式存储比特币历史价格数据，位于 `public/btc-price.csv`，覆盖 2013-04-28 至今的每日数据。

CSV 文件格式：
```csv
date,btc price
2024-01-01,42500.00
2024-01-02,43200.00
...
```

### 更新价格数据

项目包含 Python 脚本用于更新比特币价格数据：

```bash
cd scripts
python update_btc_price.py
```

脚本会从 CoinGecko API 获取最新的比特币价格数据并更新 CSV 文件。

## 📊 技术指标说明

### 移动平均线 (MA)
移动平均线是技术分析中最常用的指标之一，通过计算一定周期内的平均价格来平滑价格波动，帮助识别趋势：

- **金叉** - 短期均线上穿长期均线，通常被视为买入信号
- **死叉** - 短期均线下穿长期均线，通常被视为卖出信号
- **支撑位** - 价格下跌时，均线可能成为支撑
- **压力位** - 价格上涨时，均线可能成为阻力

### AHR999 指数
由微博用户 ahr999（九神）提出，详见其著作《囤比特币》第十五章。该指标隐含了比特币短期定投的收益率及币价与长期趋势估值的偏离度：当币价同时低于 200 日定投成本和指数增长估值时（即 AHR999 < 1），历史上往往是较好的囤币时机；小于 0.35 则为历史级底部区域。

## 🔧 自定义配置

### 修改均线周期
编辑 `src/lib/btc.js` 中的 `MA_DAYS` 数组：
```javascript
export const MA_DAYS = [50, 200, 350, 700, 1000, 1400, 2411];
```

### 修改均线颜色
编辑 `src/lib/btc.js` 中的 `MA_COLORS` 对象：
```javascript
export const MA_COLORS = {
  50: '#FF6B6B',
  200: '#4ECDC4',
  // ...
};
```

### 调整 AHR999 分区阈值
编辑 `src/lib/btc.js` 中的 `getAhr999Zone` 函数，可自定义四档分区的边界与文案。
